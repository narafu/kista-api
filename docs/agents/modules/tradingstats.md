## com.kista.tradingstats (`:trading-core`)

com.kista.tradingstats/ ← Spring Modulith 모듈(CLOSED, 2026-09-30 `trading`에서 분리) — 계좌·증권사(Toss) 통계, 백테스트, 포트폴리오, summary/equity-curve/cycles 조회 전용. **trading 핵심(주문/사이클 실행 이력)의 공개 계약(`"domain"`/`"port"`)만 읽는 단방향 소비자**라 trading은 이 모듈을 모른다(`trading → tradingstats` 참조 0, `ModulithArchitectureTest`가 순환을 잡는다). "domain"(domain.model+domain.model.backtest)·"usecase"·"port" 3개 NamedInterface 공개 — 외부 소비자는 아직 없어 사실상 선언용이며 application.service·domain.backtest·adapter.*는 internal. 소유 엔티티·JPA 리포지토리 없음(`TradingApplication`의 `@EntityScan`/`JpaRepositoryConfig` 대상 아님). `TradingApplication.scanBasePackages`·`@ConfigurationPropertiesScan`(`AlpacaProperties`)에는 명시 등록돼 있다
  domain/model/       ← InvestmentPoint(root `stats.domain.model.InvestmentPoint`와는 별개 도메인 값 — 내부 API 응답은 `contract.stats.InvestmentPointsResponse`, `StatsContractMapper`가 매핑)/`BenchmarkGranularity`는 `sharedkernel` 공용 enum + StatsSummary/EquityCurve/EquityPoint/CyclePerformancePage/CyclePerformance/StrategyTypeStats(summary/equity-curve/cycles 타입) + DailyCandle(백테스트 일봉 OHLC). domain.model.backtest(BacktestCommand/BacktestPoint/BacktestResult/BacktestSummary)와 함께 "domain"
  domain/backtest/    ← internal — BacktestEngine/FillSimulator. `com.kista.matching`을 직접 `new`해 소비
  application/        ← MonthlyReturnCalculator(public — CyclePosition/StrategyCycle로 시간가중수익률·투자지수 계산하는 순수 계산기, 로직 SSOT는 코드). 모듈 밖 소비자가 없어 NamedInterface 없음(internal)
  application/usecase/ ← AccountStatisticsUseCase/PortfolioUseCase/BrokerStatisticsUseCase/BacktestUseCase/TradingStatsUseCase/InvestmentPointsQuery — "usecase". `PortfolioUseCase` 결과는 내부 API(`/api/internal/trading/stats/portfolio/**`)로 root admin `PortfolioQueryHttpAdapter`(텔레그램 봇 `/status`·`/history`)가 소비한다
  application/port/output/ ← HistoricalCandlePort(AlpacaCandleAdapter 구현, BacktestService 소비) — "port"
  application/service/ ← internal — AccountStatisticsService/PortfolioService/BacktestService/BrokerStatisticsService/TradingStatsService/InvestmentPointsQueryService + TradingStatsResultCache(summary/equity-curve 5분 TTL — root `StatsResultCache`(벤치마크 10분)와 별개 인스턴스)
                         **`BrokerStatisticsService`(구 `TossStatisticsService`)**: 증권사 통계 capability는 broker의 벤더 중립 `BrokerStatisticsPort`(캔들/종목정보/환율/장 캘린더/증권사 계좌 목록 — `BrokerCandle`/`BrokerStockInfo`/`ExchangeRateQuote`/`MarketCalendarDay`/`BrokerAccountInfo` 반환)를 `BrokerStatisticsPorts.find(account.broker())`로 조회해 위임한다. 미지원 증권사(KIS/MOCK)는 `IllegalArgumentException`(400, 메시지 `"<BROKER> 브로커는 <Port>를 지원하지 않습니다"` 불변). Toss 벤더 타입(`broker.domain.model.toss.*`)은 broker 밖 참조 금지(ArchUnit 잠금)
  adapter/out/alpaca/ ← internal — AlpacaCandleAdapter(HistoricalCandlePort 구현)/AlpacaConfig/AlpacaProperties
  adapter/in/web/     ← internal — DashboardController/StatisticsController(KIS live)/TossStatisticsController(외부 HTTP API 불변 — 경로·DTO 필드가 kista-ui 소비, `@Tag` "통계 (Toss 전용)"·DTO 클래스명 `Toss*Response`도 openapi.json 스키마명이라 유지)/BacktestController/TradingStatsController(summary/equity-curve/cycles)/TradingStatsInternalController(`/api/internal/trading/stats/investment-points`·`/exchange-rate`, root `InvestmentPointsHttpAdapter`/`CurrentExchangeRateHttpAdapter`가 소비)/PortfolioQueryInternalController + dto/(TossCandleResponse는 market 사본과 별개 응답 계약(b))

웹 슬라이스 테스트(`@WebMvcTest`)는 `com.kista.tradingstats` 아래에 `@SpringBootConfiguration`이 없어 `@ContextConfiguration(classes = TradingApplication.class)`를 명시한다. `TradingApplication`은 앱셸 `com.kista.tradingweb`에 있다. 예외 매핑은 앱셸 `tradingweb.TradingExceptionHandler`(프로세스 전역 advice)가 담당한다.
