## com.kista.tradingstats (`:trading-core`)

com.kista.tradingstats/ ← Spring Modulith 모듈(CLOSED) — 계좌·증권사(Toss) 통계, 백테스트, 포트폴리오, summary/equity-curve/cycles 조회 전용. **trading 핵심(주문/사이클 실행 이력)의 공개 계약(`"domain"`/`"port"`)만 읽는 단방향 소비자**라 trading은 이 모듈을 모른다(`trading → tradingstats` 참조 0, `ModulithArchitectureTest`가 순환을 잡는다). "domain"(domain.model+domain.model.backtest)·"usecase"·"port" 3개 NamedInterface 공개 — 외부 소비자는 아직 없어 사실상 선언용이며 application.service·domain.backtest·adapter.*는 internal. 소유 엔티티·JPA 리포지토리 없음(`TradingApplication`의 `@EntityScan`/`JpaRepositoryConfig` 대상 아님). `TradingApplication.scanBasePackages`·`@ConfigurationPropertiesScan`(`AlpacaProperties`)에는 명시 등록돼 있다
  domain/model/       ← InvestmentPoint(root `benchmark.domain.model.InvestmentPoint`와는 별개 도메인 값 — 내부 API 응답은 `contract.stats.InvestmentPointsResponse`, `StatsContractMapper`가 매핑)/`BenchmarkGranularity`는 `sharedkernel` 공용 enum + StatsSummary/EquityCurve/EquityPoint/CyclePerformancePage/CyclePerformance/StrategyTypeStats(summary/equity-curve/cycles 타입) + DailyCandle(백테스트 일봉 OHLC). domain.model.backtest(BacktestCommand/BacktestPoint/BacktestResult/BacktestSummary)와 함께 "domain"
  domain/backtest/    ← internal — BacktestEngine/FillSimulator. `com.kista.matching`을 직접 `new`해 소비. VR은 운영 등록과 같은 조건으로 돈다 — 램프 8파라미터는 trading `VrRampParams.withDefaults()`(BacktestCommand.vrRamp()), 초기 V 미입력 시 첫 캔들 종가 × 보유수량, bandWidth/intervalWeeks는 `StrategyCreationPolicyPort` 허용값만. 타이밍 계약: 캔들 D 처리 끝에 만든 주문은 D+1 캔들로 체결 판정하고, 주문 기준가(전일종가·캡)는 D 종가(운영의 S-1 확정 종가와 동일, 워밍업 프리픽스 없음). PRIVACY 기준표 맵 키는 표가 적용되는 세션 날짜라 엔진은 다음 캔들 날짜로 조회한다. LIMIT은 시가가 유리하게 열리면 시가 체결
     예산·사이클 계약: 주문 계획 직후 운영 `TradingOrderBudgetAllocator`와 같이 BUY 지정가 합계(보정 포함)가 예수금(전략 잔고 + 유휴 현금)을 넘으면 그날 BUY를 전부 거절하고 SELL만 접수한다(예수금 0 클램프 없음). INFINITE·PRIVACY 청산 후 재시작은 `cycleSeedType`(null=MAX 전액 이월, NONE=매매 중단, MAINTAIN=시작 금액으로 재시작·초과분은 평가금에만 잡히는 유휴 현금, 가용 현금이 시작 금액 미만이면 중단 — 운영 잔고검증 ON 의미론). VR은 무시. 원금·사이클 시작 금액의 시작 보유분은 첫 캔들 종가 평가금(수익률 기준과 동일). CAGR은 365일 미만 구간이면 null
     캔들은 Alpaca `adjustment=split`(분할만 수정) — 배당 수정(all)은 과거 가격을 낮춰 FIDA 기준표·평단가 입력(원가격)과 어긋나고, raw는 분할(TQQQ·USD 2025-11-20 등)에서 가격이 계단처럼 뛴다. 한계: 분할 이전 시작일에 그 시절 원가격으로 initialAvgPrice·vrInitialValue를 넣으면 분할 수정 시리즈와 어긋난다. 수수료·세금·환전·배당은 미반영(고정 경고 문구로 고지)
  application/        ← MonthlyReturnCalculator(public — CyclePosition/StrategyCycle로 시간가중수익률·투자지수 계산하는 순수 계산기, 로직 SSOT는 코드). 모듈 밖 소비자가 없어 NamedInterface 없음(internal)
  application/usecase/ ← AccountStatisticsUseCase/PortfolioUseCase/BrokerStatisticsUseCase/BacktestUseCase/TradingStatsUseCase/InvestmentPointsQuery — "usecase". `PortfolioUseCase` 결과는 내부 API(`/api/internal/trading/stats/portfolio/**`)로 root admin `PortfolioQueryHttpAdapter`(텔레그램 봇 `/status`·`/history`)가 소비한다
  application/port/output/ ← HistoricalCandlePort(AlpacaCandleAdapter 구현, BacktestService 소비) — "port"
  application/service/ ← internal — AccountStatisticsService/PortfolioService/BacktestService/BrokerStatisticsService/TradingStatsService/InvestmentPointsQueryService + TradingStatsResultCache(summary/equity-curve 5분 TTL — root `BenchmarkResultCache`(벤치마크 10분)와 별개 인스턴스)
                         **`BrokerStatisticsService`**: 증권사 통계 capability는 broker의 벤더 중립 `BrokerStatisticsPort`(캔들/종목정보/환율/장 캘린더/증권사 계좌 목록 — `BrokerCandle`/`BrokerStockInfo`/`ExchangeRateQuote`/`MarketCalendarDay`/`BrokerAccountInfo` 반환)를 `BrokerStatisticsPorts.find(account.broker())`로 조회해 위임한다. 미지원 증권사(KIS/MOCK)는 `IllegalArgumentException`(400, 메시지 `"<BROKER> 브로커는 <Port>를 지원하지 않습니다"` 불변). **계좌 무관 환율 `currentExchangeRate()`**(내부 API `/exchange-rate`용)는 환율 소스 증권사를 상수 `EXCHANGE_RATE_BROKER = Broker.TOSS`(환율은 계좌 무관 공개 API — Toss가 유일한 제공자라 고정, 제공자가 늘면 정책으로 승격)로 명시하고 `BrokerStatisticsPorts.find(TOSS)`로 구현체를 고른다 — 컨트롤러가 `ExchangeRatePort`를 직접 주입하지 않으므로 KIS 통계 어댑터가 `BrokerStatisticsPort`를 추가 구현해도 빈 모호성이 생기지 않는다(포트 없으면 `IllegalStateException`). Toss 벤더 타입(`broker.domain.model.toss.*`)은 broker 밖 참조 금지(ArchUnit 잠금)
  adapter/out/alpaca/ ← internal — AlpacaCandleAdapter(HistoricalCandlePort 구현)/AlpacaConfig/AlpacaProperties
  adapter/in/web/     ← internal — DashboardController/StatisticsController(KIS live)/TossStatisticsController(외부 HTTP API 불변 — 경로·DTO 필드가 kista-ui 소비, `@Tag` "통계 (Toss 전용)"·DTO 클래스명 `Toss*Response`도 openapi.json 스키마명이라 유지)/BacktestController/TradingStatsController(summary/equity-curve/cycles)/TradingStatsInternalController(`/api/internal/trading/stats/investment-points`·`/exchange-rate` — 각각 `InvestmentPointsQuery`·`BrokerStatisticsUseCase.currentExchangeRate()` 유스케이스만 주입, root `InvestmentPointsHttpAdapter`/`CurrentExchangeRateHttpAdapter`가 소비)/PortfolioQueryInternalController + dto/(TossCandleResponse는 market 사본과 별개 응답 계약(b))
