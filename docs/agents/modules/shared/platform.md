## com.kista.shared.platform (`:shared`)

**빈 등록**: 앱(root·trading-core)은 `com.kista.shared`를 컴포넌트 스캔하지 않는다. `com.kista.shared.platform.PlatformAutoConfiguration`(`@AutoConfiguration`, `@AutoConfigureOrder(HIGHEST_PRECEDENCE)` — Boot의 `@ConditionalOnMissingBean` 기본 `SecurityFilterChain`·`JwtDecoder`보다 먼저 평가돼야 중복 등록이 없다)이 `shared/src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`로 등록되며 `@EnableConfigurationProperties({TelegramProperties, InternalApiProperties})`와 `@Import` 목록(Security/Jwt/필터 2종/Redis/Telegram/InternalApi/Metrics/AesCrypto/AccountNoHasher/SchedulerJobRunner/SchedulerLockService/JpaAuditing)으로 빈을 올린다. **platform에 새 빈(@Component/@Configuration)을 추가하면 이 `@Import` 목록에도 넣어야 한다** — 누락 시 두 앱에서 조용히 빠진다. `@Import`로 등록된 빈의 이름은 FQCN이다. `@WebMvcTest` 슬라이스는 더는 `JwtAuthFilter`/`InternalTokenAuthFilter`를 스캔으로 얻지 못하므로 필요한 테스트가 직접 `@Import`한다. 자체 `@EnableAutoConfiguration` 컨텍스트를 띄우는 테스트는 보안·JWT가 필요 없으면 `PlatformAutoConfiguration`을 exclude한다(예: `HousingBenchmarkApiDocsTest`).
