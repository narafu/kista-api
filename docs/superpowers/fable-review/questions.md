## 항목 틀

```
### Q-NN <한 줄 제목>
- 상태: 미답 | 답변됨 | 사용자 결정 필요
- 묶음·태스크: S2 / 지침서 08 T1
- 걸린 곳: 지침서의 어느 문장(절 번호와 인용)이 무엇과 맞지 않는가, 또는 어느 중단 조건인가
- 근거: `파일:줄`과 확인한 명령·출력(가장 짧은 결정적 한 줄)
- 선택지: 실행 세션이 보는 안 1~3개와 각각의 결과
- 멈춘 범위: 이 질문 때문에 멈춘 태스크, 계속 진행 중인 태스크
```
