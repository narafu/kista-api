# 수수료·환전·세금 (guide/costs-and-tax/)

- 원본 URL: https://quantstack.app/guide/costs-and-tax/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 거래수수료: 약정금액의 0.07~0.25%(+최소수수료 가능, 미국 현지 SEC·FINRA 소액). 예: 원금 4000만, 40분할, 0.1% → 매수 4만+매도(4400만) 4.4만 = 사이클당 약 8.4만(연 4회 34만, 원금 0.84%). 최소수수료 있으면 소액 분할 불리.
- 환전 스프레드: 편도 0.2~0.5%, 왕복 0.4~1%. 달러를 계좌에 두면 절약. 통합증거금 환율 확인.
- ETF 운용보수 연 0.9% 안팎 + 3배 노출용 2배 차입이자(금리 0%→거의 없음, 5%→연 10% 안팎).
- 세금: 양도소득세 과세표준 = 연간 해외주식 매매이익 − 손실 − 필요경비 − 기본공제 250만원, 세율 22%(지방세 포함), 같은 해 손익통산, 다음 해 5월 직접 신고, 증권사 합산. 배당: 미국 15% 원천징수, 금융소득 합계 연 2000만원 초과 시 종합과세.
- 회전율 높은 규칙매매는 매년 과세(세금 드래그). 세금 때문에 매도 규칙을 어기지 말 것.
- 사이클 손익분기(원금 4000만, 왕복 환전 1회, 수수료 0.1%, 3개월): 수수료 8.4만(0.21%) + 환전 16만(0.40%) + 보수 9만(0.23%) = 33만(0.84%); 세후 ≈ +1.1%.
