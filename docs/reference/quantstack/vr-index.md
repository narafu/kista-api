# VR 5.0 개요 (vr/)

- 원본 URL: https://quantstack.app/vr/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 개념: 레버리지 ETF 평가금이 따라갈 목표곡선 V를 두고, 평가금이 밴드 이상 벗어났을 때만 매매. 2주 1회 판단, 현금(Pool) 상시 보유. 고안자가 V1~V4를 정리하고 5.0 단일 버전 유지, 유형(적립/거치/인출)별로 파라미터만 상이.
- 문서 구성: 핵심 용어&공식 / 운용 절차 / 백테스트(G별·밴드폭별 10년) / 적립식 / 거치식 / 인출식 / 유형 전환.
- 핵심 공식 요약: 다음 V = 현재 V + P/G ± 적립금(or 인출금); 밴드 상단 V×1.15, 하단 V×0.85; 평가금>상단 매도, <하단 매수(Pool 한도 내), 밴드 안 거래 없음.
- 유형 비교표: 적립식(+적립, Pool한도 75%, G /10 시작, 쉬움, VR 2~4기) / 거치식(없음, 50%, /10, 보통, VR 0~1기) / 인출식(−인출, 25%, /20, 어려움, VR 5기 2025-07~).
- 공통 원칙: 사이클 2주 1회, TQQQ 중심, 밴드폭 ±15% 오피셜(±10% 등 허용), 유형 전환 수개월 단위 OK·2주 단위 금지, 핵심은 매도, 길게 가는 방법론.
- 해설: 무한매수법(기준=평단, 매일, 사이클 있음, 손실 매도는 소진 국면만) vs VR(기준=V, 2주, 끝 없음, 평단 미등장, 손실 상태 매도가 정상 규칙). 읽는 순서: 용어&공식→운용절차→G·밴드 분석→유형→백테스트. 시작 전: 자금설계, 수수료·환전·세금, 무한매수법 vs VR.
- 전체 규칙·수치: value-rebalancing.md
