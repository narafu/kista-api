# 인출식 VR (vr/withdrawal/)

- 원본 URL: https://quantstack.app/vr/withdrawal/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 정의: 매 사이클 인출. 다음 V = V + P/G − 인출금. VR 최종 목표 단계. Pool 한도 인출 후 25%. G 시작 /20 이상→/30(적립·거치 /10보다 한 단계 보수적).
- 공개 사례: 블로그 196~252주차 개인 인출식(월 600만원→1500만원), 원금 감소 구조·최종 원금 전부 인출 후 수익분만 남음. VR 5기(2025-07~): 첫 공개 운용, 원금 2만$(N배수), 팬딩에서만 중계(카페 외부).
- 장점: 생활비 조달 구조, Pool 있는 한 인출 지속, 급락 시 일시 거치식 전환. 주의(위험): 난이도 최상(고안자도 1년 이상 직접 운용 후 공개), Pool 소진 시 인출 중단, 수개월 단위 전환 OK·2주 단위 금지.
- 해설: 인출금=브레이크, P/G>인출 V↑/=정체/<V↓, 지속 조건 인출 ≤ P/G(V 200000·G/20·P 42000 → 2100/사이클, 연 ≈54600, V의 27%), G↑ 인출여력↓, 한도 25% 이유, 수익률 순서 위험 표(A −40/+60 vs B +60/−40), 대응=하락장 거치식 전환(계좌 밖 몇 개월치 생활비 필요), 시작 체크리스트 7항(value-rebalancing.md §B).
