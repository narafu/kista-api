## A. 규칙 (사이트의 "규칙 정리" 부분, 의미 보존)

### A1. 원금·분할
- 원금을 20/30/40분할 중 선택(분할↓ = 공격적, 분할↑ = 안정). 예: 2만$ → 20분할 1회 1000$ / 40분할 500$.
- TQQQ·SOXL 동시 진행 시 원금은 독립 설정(한 계좌 가능). 20/40분할 동시 진행은 계좌 분리 권장.
- 종목: 초심자는 TQQQ만, 익숙해지면 SOXL 병행(수익률은 SOXL이 더 높다고 서술). TQQQ/SOXL 이외 종목은 오피셜 아님.
- 사이트의 별% 공식은 20·40분할만 명시. 30분할 공식은 명시 없음 → 불명확(§E).

### A2. T값 (V4.0 변경점: 계산식이 아니라 "누적 가산")
일반모드 기준:
| 사건 | T 변화 |
|---|---|
| 1회분 매수 완료 | T + 1 |
| 절반 매수 | T + 0.5 |
| 쿼터매도 발생 | T × 0.75 |
| 지정가매도 후 LOC매수되는 경우 | (T × 0.25 + 1) 또는 (T × 0.25 + 0.5) |
| 미체결 | 변화 없음 |
- 소수점 자릿수 제한 없음(예: T = 5.165479525).
- V3.0까지의 T = 매수누적액/1회매수액은 V4.0에서 폐기(1회매수금이 매일 변해 순환 문제).

### A3. 별지점·별%
| 설정 | 별% |
|---|---|
| TQQQ 20분할 | 15 − 1.5T (%) |
| TQQQ 40분할 | 15 − 0.75T (%) |
| SOXL 20분할 | 20 − 2T (%) |
| SOXL 40분할 | 20 − T (%) |
- 별지점 = 평단 × (1 + 별%). (V3.0과 동일하다고 서술)
- T가 분할수의 절반 초과 → 후반전(별%가 마이너스로 진입).
- 매수점 = 별지점 − 0.01$, 매도점 = 별지점 그대로(같은 종가에서 매수·매도 동시 체결 방지).
- 모든 설정에서 T = 분할수일 때 TQQQ −15%, SOXL −20%; T = 분할수/2에서 0%.

### A4. 1회매수금
- 20분할: 잔금 / (20 − T), 40분할: 잔금 / (40 − T). 매일 미세 변동(T, 잔금 반영).
- 예(원금 2만$, 40분할): 1일차 500$ 시도 → 478$ 실매수 → 잔금 19522$, T=1; 2일차 = 19522/39 = 500.56$.
- 해설표: 0일 20000/40 = 500.00 · 1일 체결 478 → 잔금 19522, T=1, 다음 19522/39=500.56 · 2일 미체결 → 변화 없음 · 3일 500.56 체결 → 잔금 19021, T=2, 다음 19021/38 = 500.56 (사이트 표기. 19522−500.56=19021.44, /38 = 500.564이므로 표기 19021은 반올림 표기).
- (해설) 분모 (분할수 − T)가 1이 되는 마지막 회차에 잔금 전액 소진.

### A4-1. 매수 (전부 LOC)
- **처음 매수 (T=0, 보유 0)**: 무조건 1회 매수 의도. 전일 종가보다 10~15% 위 값에 LOC매수(큰수). 그 아래로 단계별 LOC매수 추가. 예: TQQQ 종가 45.93$ → 큰수 51.44$ (12개), 47.53$ (1개), 44.13$ (1개), …
- **전반전 (T = 1 ~ 분할수/2 미만; 40분할이면 T=0~19.999 로 표기)**: 1회매수액의 절반 별지점 LOC매수, 절반 평단 LOC매수, 아래로 LOC매수 추가(큰 하락 대비).
- **후반전 (분할수/2 이상 ~ 분할수−1; 40분할이면 T=20~39)**: 1회매수액 전체를 별지점 LOC매수(평단보다 아래), 아래로 LOC매수 추가.
- T > 분할수 − 1 → 리버스(소진)모드 진입.

### A4-2. 매도 (전·후반 공통)
- 보유수량 1/4: 별지점 LOC매도(쿼터매도). 나머지 3/4: TQQQ +15% / SOXL +20% 지정가매도.
- 타이밍: 지정가매도는 프리장 시작(서머타임 17시 / 비서머타임 18시, KST)에 걸어 프리~본~애프터까지 유지. LOC매수/매도는 본장 중 언제든 가능. 주간장 이용 금지.

### A5. 종료·재시작
- 보유 0 → 사이클 종료. 지정가매도 후 급락으로 LOC매수가 걸리면 종료 아님(계속 진행).
- 재시작 시 복리/단리 자유(원 방법론 예시: 1년 단위 복리 운용 후 원금 재설정).
- 큰수 매수는 증권사의 현재가 ±20% 밖 주문 제한 우회용 실무 장치(방법론 규칙 자체 아님)라고 서술.

### A6. 리버스모드 (소진 구간; 기존 쿼터손절 대체)
- 발동: 원금 소진 시. 20분할 T > 19, 40분할 T > 39. 잔금이 남아 있어도 리버스에서 같이 사용.
- **별지점(리버스 전용)** = 직전 5거래일 종가의 평균(월요일 본장 전이면 지난주 월~금 평균). 첫매도는 무조건 매도라 별지점 불필요.
- **매도(무한매도)**
  - 첫날 무조건 매도: 20분할 전체 개수의 1/10, 40분할 1/20. 자연수 아니면 내림(200개 → 10등분 20개 / 20등분 10개; 198개 → 19개 / 9개). MOC 매도.
  - 둘째날 이후: 별지점 위에서 매도 시도. 매도개수 = 직전 보유개수의 1/10(20분할)·1/20(40분할). 예(40분할, 200개): 1일차 10(잔190) → 2일차 190/20=9(잔181) → 3일차 181/20=9(잔172) → 4일차 172/20=8.
- **매수(쿼터매수)**: 첫날은 매수 없음. 둘째날부터 잔금/4만큼 별지점 아래에 LOC매수. 잔금 = 매수 후 잔금 + 직전 매도금의 누적. 예: 2만$ 40분할, T>39 진입 시 잔금 400$ → 1일차 MOC매도로 300$ 발생 → 2일차 (400+300)/4 = 175$ 매수 시도 → 3일차 이후 동일하게 총 잔금/4.
- **T 계산(리버스)**: 20분할 — 매도 T×0.9, 매수 T+(20−T)×0.25. 40분할 — 매도 T×0.95, 매수 T+(40−T)×0.25. 예(40분할): T=39.5에서 MOC매도 → 37.525; 둘째날 쿼터매수 → 37.525+(40−37.525)×0.25 = 38.14375.
- **종료 → 일반모드 복귀**: 종가가 평단 대비 TQQQ −15%, SOXL −20% "보다 커지면(위로 올라오면)" 확인 다음날부터 일반모드 재시작(일반모드 마지막 T의 쿼터매도 기준과 동일). 하루 만에 끝날 수도 있음. 리버스 기간의 매매는 모두 손절 상황(종가<평단).
- **복귀 시 승계**: T는 리버스에서 쓰던 값 그대로, 1회매수금은 일반 공식 잔금/(분할수−T). 복귀 후 다시 T가 1회분도 안 남으면 다시 리버스.
- **주의(callout, 위험)**: 리버스 중에도 외부 자금 추가 투입 없음(설정 원금 안에서 해결). 규칙을 안 지키면 "무한매수법"이 아닌 개인 변형. 재가공/편집/유튜브 재배포 금지(원글 공지).

## B. 계산기 로직 (https://quantstack.app/tools/calculator/ + calc.js, 사이트 공개 JS)
### B1. 입력·출력
- 일반모드 표: 입력 = 버전(V4.0/V3.0/V2.2), 종목(TQQQ/SOXL; V2.2는 비활성), 분할수(20/40), 평단가(기본 50). 출력 = T=1..분할수 각 행의 별%, 별지점, 매수가, 매도가, 구간(전반전/후반전).
- 퍼센트 표: 평단 불필요, T별 별%(매도=매수), 구간.
- 리버스 시뮬레이터: 입력 = 분할수(20/40), 현 보유수량(기본 200), 시뮬 일수(기본 15, 1~60), 5일 종가 평균(기본 35), 평단가(기본 50). 출력 = 일자별 직전 보유·매도 수량·잔여·주문 종류(D1 MOC 매도, 이후 "별지점 위 LOC매도"), 종료선 가격(평단×0.85 / ×0.80).
### B2. 코드 공식 (그대로)
```
starPct(T): V2.2 → 10 − (T/2)·(40/n)
            V3/V4 TQQQ → 15 − (30/n)·T ;  SOXL → 20 − (40/n)·T      (n = 분할수; n≤0이면 40)
starPx   = round2(avg·(1+starPct/100))        // round2 = Math.round(x*100)/100
buyPx    = round2(starPx_unrounded − 0.01)    // 코드: buyPx = round2(h(s)) , h(s)=s−0.01, s는 반올림 전 별지점
sellPx   = starPx(round2)
kind     = T ≤ n/2 ? 전반전 : 후반전           // 계산기 표 기준: T = n/2 는 "전반전"
reverse sell qty = floor(holding / (n/2))     // 20분할 → /10, 40분할 → /20 (첫날 포함 매일 동일식), holding ≤ 0이면 중단
```
- 20·40분할 외 분할수(30 등)도 위 일반식이 적용되나 UI 선택지는 20/40.
### B3. 검증용 값 (TQQQ 40분할, 평단 50 → 계산기 출력)
T=1 14.25% 별지점 57.13 매수 57.12 / T=10 7.50% 53.75·53.74 / T=20 0.00% 50.00·49.99 (전반전 표기) / T=21 −0.75% 49.63 (후반전) / T=30 −7.50% 46.25 / T=40 −15.00% 42.50·42.49. 퍼센트 표(TQQQ 40분할)는 T마다 0.75%p씩 감소(14.25 … −15.00).
- 별% 비교: V2.2 40분할 10−0.5T (T=40 −10%). 20분할 TQQQ T=10 → 0%, T=20 → −15%.
- 리버스 시뮬 예(40분할, 200주): D1 200→10→190, D2 190→9→181, D3 181→9→172, D4 172→8→164, D5 164→8→156, D6 156→7→149, D7 149→7→142, D8 142→7→135, D9 135→6→129, D10 129→6→123, D11 123→6→117, D12 117→5→112, D13 112→5→107, D14 107→5→102, D15 102→5→97.
- 잔량 감소: 40분할 ×0.95ⁿ (5일 77%, 10일 60%, 14일≈50%, 20일 36%), 20분할 ×0.9ⁿ (5일 59%, 10일 35%, 14일 23%, 20일 12%).
- 종료선 = 일반모드 별% 직선의 끝값(T=분할수): TQQQ −15%, SOXL −20%(20·40분할 공통).

## C. 사이트 코드 구현 (로그인 전용 포트폴리오, "사이트의 해석" — 공식 규칙으로 단정 금지)
출처: AccountDetailPage 번들. V4.0 계정(전략 키 infinite_v4)의 "오늘의 주문" 카드 로직.
- **1회매수금**: V4 = `max(0, 잔금 / max(1, n − T))`, 잔금 = 입금−출금−매수액+매도액 누적. V2.2/V3.0 계정 = 원금/n(반복리 미구현).
- **구간 판정(주문 카드)**: `T ≥ n/2` → 후반전, 아니면 전반전. (※ 계산기 표는 T=n/2를 전반전으로 표기 → 사이트 내부 불일치)
- **주문 구성**(R = 1회매수금, buyPx = 별지점 − 0.01, 모든 가격 소수 2자리 반올림):
  - 후반전: 별지점 LOC매수 `floor(R / buyPx)`주 (R 전체).
  - 전반전: 별지점 LOC매수 `floor((R/2) / buyPx)`주, 그리고 평단 LOC매수 `floor((R − 별지점매수금액) / 평단)`주(= 절반 + 별지점 매수에서 남은 자투리). 평단 매수가 = 평단 그대로(−0.01 없음).
  - **아래 단계 LOC매수("자투리 활용", 각 1주)**: V = (별지점 매수 수량 + 평단 매수 수량). k=1,2,…에 대해 가격 `round2(R / (V + k))`, 그 값이 기준가(후반전=별지점 매수가, 전반전=평단)보다 낮을 때만 1주 단계로 채택, 최대 10단계, 가격 ≤ 0.01이면 중단. (예 평단50, TQQQ 40분할, R=500, T=10 → 별지점 53.75, 매수 53.74×4주 + 평단 50×5주, V=9, 단계가 45.45, 41.67, 38.46, 35.71, 33.33, 31.25, 29.41, 27.78, 26.32, 25.00. T=25 후반전 → 매수가 48.12×10주, V=10, 단계 가격 위와 동일.) 이 식은 사이트 본문에는 서술이 없다. 본문 예시 51.44(12개)/47.53/44.13과 구조가 유사(R/12≈51.4, R/13≈47.5, R/14≈44.1 → R≈617~618)하나 정확히 일치하지는 않음.
  - 매도: 쿼터매도 = `floor(floor(보유)/4)`주를 별지점(=round2(평단×(1+별%))) LOC. 나머지(보유−쿼터)를 지정가매도 평단 × (1 + 상한%), 상한% 기본 TQQQ 15 / SOXL 20(V2.2는 10), 사용자가 10/15/20 선택 가능. 별% 부호 따라 별지점이 평단 아래일 수 있음.
- **처음 매수(T=0)**: 1회매수금 = 원금/n. 큰수 가격 = round2(종가 × 1.13) (코드는 +13% 고정; 사이트 본문은 10~15%, 예시 51.44는 +12%), 수량 = `floor(1회매수금 / 종가)`. "그 아래 단계 LOC" 매수는 이 화면에서 생성하지 않음.
- **T 갱신(거래 기록 기준, 날짜별)**: 그날 시작 T와 그날 1회매수금(= 잔금/(n−T), 입출금 반영 후)을 고정. ① 그날 매도(지정가·쿼터매도·MOC) 체결마다 `T ← T × (매도 후 보유 / 매도 전 보유)` (쿼터매도면 ×0.75, 3/4 지정가면 ×0.25 로 자연 환산) ② 보유 0이 되면 T=0·평균단가 초기화(사이클 종료) ③ 그날 매수 체결액 합 y에 대해 `ΔT = max(0, round(y / 1회매수금 × 2) / 2)` (0.5 단위 반올림; 비율 <0.25이면 +0 "소액 체결") ④ `T ← clamp(T, 0, n)`. 순서는 매도 먼저, 매수 나중. (예: 478/500=0.956 → +1)
- 평균단가: 이동평균(매도 시 보유 비례로 원가 차감). 수량은 정수만(`floor`).
- **리버스모드는 구현되어 있지 않다**(코드에 리버스 로직 없음). 분할수 UI 선택지는 20/30/40. 30분할이면 별% 일반식 `15−(30/n)T`(=15−T) / `20−(40/n)T`가 적용됨(사이트 본문엔 없음).
- 변경 이력(changelog): 2026-08-24 T 계산을 수량 기준→금액 기준으로 수정(부분 체결 시 T 과대 문제), 2026-07-01 후반전 매수금액이 절반으로 잡히던 버그 수정, 2026-05-21 매수 수량 정수 강제·"아래 단계 LOC 매수"를 자투리(잔액) 공식으로 수정, 2026-04-20 V4.0 전·후반 매수 규칙 구현 오류 수정(1회매수금 잔금 연동).

## D. quantstack 해설 (해설 부분 요약 — 원 규칙 아님)
- 개정 요지: T를 "이력(나눗셈)"에서 "상태(가산)"로. 쿼터매도 시 T×0.75 → 별%가 다시 올라가 매도 문턱 상승(포지션 크기와 목표 수익 연동).
- 1회매수금 = 잔금/(분할수−T): 실탄이 정확히 마지막 회차에 소진, 중간 매도 시 잔금↑·T↓로 부드럽게 재조정, 목표보다 적게 체결된 금액은 이후 회차에 분배.
- 첫 매수를 종가보다 높게 거는 이유: LOC는 종가로 체결되므로 체결 확률을 높이려는 장치(비싸게 사려는 것이 아님), MOC 대신 LOC를 쓰는 것은 폭등일 상한을 남기기 위함이라는 해석.
- 리버스: 쿼터매도(계단)와 달리 1/20씩 매일 매도(경사로); 잔량 등비수열이라 0이 안 됨; 별지점을 5일 평균으로 바꾼 이유=평단 기준은 도달 불가; 종료선 −15/−20%는 별% 직선 끝값; 리버스 매도는 모두 손실 확정.
- 실전 체크리스트: T는 어제 T에 가산했는가 / 1회매수액을 오늘 잔금으로 재계산했는가 / 매수 별지점−0.01, 매도(1/4) 별지점 / 3/4 지정가는 프리장 시작에 / T>분할수−1이면 리버스 / 계좌 분리(평단 혼합 금지).

## E. 불명확·모순 목록 (추측으로 메우지 않음)
1. **전/후반 경계**: V4 본문은 전반전 "T=1 ~ 분할수/2 미만(40분할이면 T=0~19.999)", 후반전 "분할수/2 이상", 동시에 "T가 절반 초과 → 후반전"이라고도 서술. 계산기 표는 T=n/2를 전반전, 포트폴리오 주문 카드는 후반전으로 처리. T=n/2에서는 별지점=평단이라 가격 효과는 같으나 매수 수량 배분(절반 vs 전액)이 다르다. 전반전 시작이 "T=1"인지 "T=0(처음 매수)"인지도 혼재.
2. **부분 체결 T 증분**: 본문은 "1회 매수 완료 +1, 절반 +0.5"뿐. 그 외 비율(예 478/500)의 처리는 미기재(예시에서 478/500 체결 후 T=1). 포트폴리오 코드는 0.5 단위 반올림. changelog는 "금액 기준" 계산이라 표현.
3. **지정가매도 후 LOC매수 T**: "(×0.25 + 1) or (×0.25 + 0.5)" — 3/4 지정가 체결 단독 시 T 영향, 쿼터매도(1/4)와 지정가(3/4)가 같은 날 모두 체결될 때의 처리는 미기재.
4. **1/4 수량 반올림**: 일반모드의 "보유수량의 1/4" 정수 처리 규칙 미기재(리버스는 내림 명시). 코드는 floor.
5. **30분할**: 분할 선택지에 있으나 별% 공식·리버스 비율(1/15?) 미기재.
6. **아래 단계 LOC매수 가격식**: 본문은 "아래로 LOC매수 추가"만 서술. 가격식은 사이트 코드(R/(V+k))에서만 확인되며 본문 예시와 정확히 일치하지 않음. 첫 매수 큰수는 본문 10~15%·예시 +12%·코드 +13%.
7. **리버스 세부**: 쿼터매수 LOC가격에 −0.01을 적용하는지, 리버스 중 3/4 지정가(+15%/+20%) 유지 여부, 같은 날 매수·매도가 모두 체결될 때 T 갱신 순서, 첫날 이후 "별지점 위" 매도가 LOC(≥별지점)인지, 잔금 "누적" 정의(예시에서 (잔금400 + 직전 매도 300)/4)의 일반화 — 모두 미기재.
8. **리버스 T 진입 기준**: "T>19/ >39" 진입 vs 일반모드 "T > 분할수−1". 사실상 동일하나 표기가 다름. T가 분할수 사이(예 39<T<40)에서 일반모드 1회매수금 = 잔금/(분할수−T)의 분모가 1 미만이 되는 경우의 처리 미기재.
9. **T 반올림**: V4는 "자릿수 제한 없음", V2.2는 "소수 셋째 자리 반올림(2024-09-05 업데이트, 원래 둘째 자리 올림)", V3.0 페이지는 "둘째 자리 올림". 버전 간 상이.
10. **해설 예시 수치**: 3일차 잔금 표기 19021(계산 19021.44), 다음 1회매수금 500.56(19021/38=500.55, 19021.44/38=500.564).
11. 사이트 본문의 "큰수 매수 증권사 ±20% 제한"은 증권사 사정이며 비율(10~15%)과의 관계는 설명되지 않음.
