# 거치식 VR (vr/lumpsum/)

- 원본 URL: https://quantstack.app/vr/lumpsum/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 정의: 추가 투입·인출 없음. 다음 V = V + P/G. Pool 한도 50%(적립식보다 보수적). VR 0기·1기, 월급 무관 포트폴리오.
- 장점: 월급 이벤트 무관, 전환 수월, 적립식과 병행 시 유연. 전환: 월급 불안정·추가 투입 어려울 때; 적립식→거치식은 TQQQ 개수를 거치식 모델에 맞추고 남는 TQQQ는 홀드/급전 시 매도.
- 해설: 0일차 세팅(P/V 평균에서 출발, 원금/(1+P/V), 표 5000/10000/20000 → 4350/8700/17400, G /20은 /1.27, 0일차 절차, 격주 같은 요일 고정, V₁ 예 8830·10154.5·7505.5, 비율 변경 가능·중간 수정 금지); 거치식은 VR의 기본형(적립/인출 항 0), 한도 50%=적립 75와 인출 25의 중간; 주의: 무거래 기간 가장 김, Pool 마르면 매도 나올 때까지 정지, 남는 TQQQ는 VR 평가금에서 제외·별도 계좌. 상세 수치 value-rebalancing.md.
