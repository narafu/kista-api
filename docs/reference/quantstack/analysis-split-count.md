# 20분할 vs 40분할 (analysis/split-count/)

- 원본 URL: https://quantstack.app/analysis/split-count/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 정액 분할매수 평단 = n / Σ(1/pᵢ) (조화평균, M·분할 수 소거). 예: 100에서 매일 −2% 10일(100, 98, 96.04, 94.12, 92.24, 90.39, 88.58, 86.81, 85.08, 83.37) Σ(1/p)=0.10970, 평단 91.16. 원금 4000만: 40분할 투입 1000만(25%)·손익 −85만 / 20분할 2000만(50%)·−171만, 평단 동일.
- 차이 3가지: 노출 속도(40분할 소진 ≈2개월, 20분할 ≈1개월), 소진까지 시간(리버스/쿼터 도달 2배 빠름), 별% 기울기 2배(별% = 15 − (30/분할수)T). T=10 비교: 40분할 7.5% / 20분할 0%; 예에서 평단 91.16 → 40분할 매도 기준 98.00(+17.5% 반등 필요) vs 20분할 91.16(+9.3%).
- 표: T=1 +14.25/+13.5, 5 +11.25/+7.5, 10 +7.5/0, 20 0/−15(소진), 30 −7.5, 40 −15(소진).
- 선택: 40분할=1년 이상 묶어둘 돈, 하락장 경험 없음, 병행; 20분할=소진 대응 경험, 원금이 작아 1회분 <1주, 회전 필요. 하지 말 것: 하락 중 40→20 변경, 분할 늘려 원금 키우기.
