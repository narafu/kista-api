# 분석·칼럼 개요 (analysis/)

- 원본 URL: https://quantstack.app/analysis/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 글 목록: 원리(변동성 끌림, 오해 5가지, TQQQ vs SOXL) / 산수(분할매수 평단, 20 vs 40분할, VR G·밴드폭) / 태도(버전 진화, 백테스트 신뢰). 읽는 순서: 변동성 끌림→분할매수의 수학, 운용 중이면 버전 진화부터.
- 작업 방식: 통설→식→숫자 확인→결과. 예: 정액 분할매수 평단은 조화평균이라 분할 수가 없다.
- 다루지 않음: 매수·매도 신호, 기대 수익률, 규칙 원문.
