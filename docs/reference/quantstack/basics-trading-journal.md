# 규칙 매매 기록법 (basics/trading-journal/)

- 원본 URL: https://quantstack.app/basics/trading-journal/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- quantstack 자체 계산·해설(원 방법론 규칙 아님)

- 목표=재현성. 거래당 5항목: 미국 거래일 날짜, 종류(매수/쿼터매도/지정가매도/리버스매도), 체결가·체결수량, 체결 금액(수수료 포함), 거래 후 T. 매일 한 줄(날짜·종류·체결가·수량·금액·거래 후 T·평단·잔금·메모), 미체결도 기록. 예: 2026-09-12 쿼터매도 T 3→2.25(×0.75).
- 사이클 요약 항목, 흔한 오류 5(주문가≠체결가, 부분 체결, T 소급, 한국 날짜, 계좌 혼합), 월 1회 증권사 잔고 대조.
