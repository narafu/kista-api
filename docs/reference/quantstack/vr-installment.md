# 적립식 VR (vr/installment/)

- 원본 URL: https://quantstack.app/vr/installment/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 정의: 2주마다 일정 금액 추가. 다음 V = V + P/G + 적립금. Pool 한도 적립 후 Pool의 75%(점진 50%, 25%로 낮출 수 있음).
- 설정 예: VR 2~4기, 소액 장기(월 10만원 수준 수십 년), 1년차 /10→/11→/12.
- 장점: 월급 기반 Pool 충전, 하락장 Pool 소진도 다음 적립금으로 복구, 거치식 전환 자유. 전환: 월 추가 투입 힘들면 거치식, 월급 인상 시 N배수, 거치식 동시 진행 권장. 주의(callout): 무리한 투입 금지(무리→지침→이탈), 최종 목표는 인출식.
- 해설: 적립금=실탄 보충+목표 상향 동시, 숫자 예 10400/10800/11200, 한도 75% 이유, 함정(하락장 증액, 적립 건너뛰기, 무리한 적립; 기준: 하락장 1년이어도 넣을 수 있는 금액), 거치식 전환 시점(부담 느낄 때 미리, 계좌 커져 적립 비중 미미할 때).
