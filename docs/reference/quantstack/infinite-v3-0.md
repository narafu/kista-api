## 규칙 (2024년 6월, 과거; 2026-03 V4.0로 개정)
- 핵심 변화(vs V2.2, "V2.2 전제 필요"): 1회매수금에 수익의 절반을 실시간 반영(반복리, 나머지 절반은 쿼터모드 대비 보관); 쿼터손절→쿼터매도 단어 통일(손절 시에도 매수금 유지); 20분할 기본(초심자는 40분할 6개월 이상 먼저 권장).
- T = 매수누적액/1회매수액(소수점 둘째 자리 올림). 1회매수액이 실시간 변함에 주의.
- 별%(20분할): TQQQ 15 − 1.5T, SOXL 20 − 2T. T=10에서 0 → 전/후반 분기. 40분할도 선택 가능(안정성↑).
- 매수금: 원금 20분할 → 1회매수금(2만$→1000$). 수익 발생 시(사이클 종료 or 중간 쿼터매도) 수익금을 40분할하여 다음 1회매수금에 반영. 예: 쿼터매도 200$ 수익 → 1000+200/40 = 1005$. 손해 시 1회매수금 변하지 않음(과거 수익 Max 기준).
- 전반전 매수(T ≤ 9.99): 1회분 절반 별% LOC, 절반 0%(평단) LOC, 아래로 LOC 추가. 후반전(T ≥ 10): 전체 별% LOC, 아래로 추가.
- 일반 매도(T ≤ 19): 누적 1/4 별% LOC(쿼터매도), 3/4 TQQQ +15%/SOXL +20% 지정가.
- 쿼터모드(19 < T < 20, 소진 구간): 누적 1/4 MOC 매도, 3/4 +15%/+20% 지정가, 그날 매수 시도 없음, MOC 후에도 1회매수액 유지, 보관했던 수익 절반을 사용해 5회 더 매수 가능, 그 기간 별%는 여전히 T값 공식, LOC매도 빠져나온 후에도 1회매수액 유지, 별% 이상 못 오르면 다시 MOC매도.
- 특징: 20분할은 40분할보다 공격적, 경험 없이는 40분할 권장. SOXL 20분할 20% 기준 3년 이동 누적수익률 최소 52%/최대 138%(백테스트).
## 해설
- 반복리: 다음 1회매수금 = 기존 + 수익금/40. 예: 사이클 수익 +200→+5→1005; +400→+10→1015; −300→유지 1015; +600→+15→1030. 수익은 절반 반복리/절반 쿼터모드 예비금(소진 시 5회분). 20분할은 기울기 2배·회전 빠름·소진도 2배 빠름. 남은 문제: 1회매수액 실시간 변동 → T 순환 참조 → V4.0 가산식.
## 불명확·모순
- "수익의 절반을 반영"이라는 서술과 예시(수익 전액/40)가 20분할에서만 맞아 보임(수익/40 = 반분 시 수익/2 ÷ 20). 분할 수와 무관하게 /40인지 불명.
- T 반올림: V2.2 "셋째 자리 반올림(2024-09-05)" vs 본 페이지 "둘째 자리 올림".
- 쿼터모드 T 범위 "19<T<20"과 일반 매도 "T ≤ 19" 경계, 40분할에서의 쿼터모드 범위 미기재. "5회 더 매수"의 1회매수액 기준 미기재.
- 해설 페이지(analysis/version-evolution)는 V3.0을 "전·후반 별지점 공식 분리"로 서술하나 본 페이지와 맞지 않음.
