# VR 유형 간 전환 (vr/convert/)

- 원본 URL: https://quantstack.app/vr/convert/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 대전제: 세 유형은 공식·사이클·매매 동일, 차이는 자금 흐름. 적립→거치, 거치→적립(예 367개→2배 734개), 거치↔인출(일시) 절차와 전환 원칙·권장 순서(VR 진행 자체가 중요, 최종 목표 인출식)·무리하지 말 것 callout → value-rebalancing.md §A9.
- 해설: 통일식 다음 V = V + P/G + C. 실제 바뀌는 것은 Pool 한도(적립→거치 75→50, 거치→인출 50→25, 인출→거치 25→50). 2주 단위 전환 금지 이유(시황 보고 바꾸면 재량 매매). 예외=하락장 인출식→거치식(인출 판단이지 매매 판단 아님, 계좌 밖 생활비 전제). 실행 체크리스트 6항(시황 아닌 내 상황 변화인가, 수개월 전 계획, 한도 변경, 남는 TQQQ 처리·VR 평가금 제외, 인출식은 인출금≤P/G, 수량 조정 매도 양도세). V 곡선은 끊지 말고 느리게.
