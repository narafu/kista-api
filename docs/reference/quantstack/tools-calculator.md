# T값/별지점 계산기 (tools/calculator/)

- 원본 URL: https://quantstack.app/tools/calculator/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 상세(입력·출력·공식·코드·검증값)는 **infinite-buying-v4.md §B** 에 통합. 여기서는 페이지 구성만 기록.
- 구성: 퍼센트 표(평단 불필요) / 일반모드 표 / V4.0 리버스(소진)모드 시뮬레이터 / "이 계산기가 하는 일" 해설 / 활용 팁.
- 지원 버전: V4.0, V3.0, V2.2(과거 비교용). 종목 TQQQ/SOXL(V2.2는 종목 무관). 분할수 20/40.
- 공식 3줄: 별% = 시작값 − 기울기×T; 별지점 = 평단×(1+별%/100); 매수가 = 별지점 − 0.01(V4.0, 매도와 겹침 방지). 설정별: V4.0 TQQQ20 15−1.5T / TQQQ40 15−0.75T / SOXL20 20−2T / SOXL40 20−T / V2.2 40분할 10−0.5T (T=분할수에서 각각 −15/−15/−20/−20/−10%).
- T 구하는 법: V2.2/V3.0 = 매수누적액÷1회매수액; V4.0 = 어제 T에 가산(1회 매수 +1, 절반 +0.5, 쿼터매도 ×0.75). V4.0에서 나눗셈으로 구하면 어긋남.
- 분할수는 사이클 중간에 바꾸지 않음. 평단은 증권사 앱 잔고에서(다른 종목 혼합 금지).
- 주문 옮길 때 확인: LOC인지(지정가 아님), 매수 별지점−0.01 / 매도(1/4) 별지점, 나머지 3/4 지정가는 프리장 시작에 별도(+15/+20%), 주문 수량 정수(소수점 주문은 LOC 미지원 사례 많음), 증권사 LOC 접수 마감은 장 마감보다 이름.
- FAQ: T 소수점 정상(연속함수); 평단 같아도 별지점 변함(T 상승); 별%가 마이너스여도 후반전 정상; V2.2·V3.0 표 차이는 시작값(10 vs 15)·기울기 차.
- callout: 학습·확인용, 주문 대행 아님, 최종 기준은 원저작자 공지.
- 활용 팁: 매일 프리장 시작 시간(17/18시)에 표 보고 LOC 주문, 평단 변경 시 자동 갱신, 모바일 홈화면 추가.
- 기본 입력값: 40분할, 평단 50, 리버스 시뮬 200주/15일/5일평균 35.
