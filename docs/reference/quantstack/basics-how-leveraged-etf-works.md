# 3배 ETF는 어떻게 만들어지나 (basics/how-leveraged-etf-works/)

- 원본 URL: https://quantstack.app/basics/how-leveraged-etf-works/

- 구성: 총수익 스왑 + 지수 선물 + 현물·현금·단기채. 매일 장 마감 무렵 익스포저를 순자산 3배로 재조정(순자산 100/익스포저 300 → 지수 +5% 후 115/315(2.74배) → 345로 리밸런싱). 오르면 사고 내리면 판다 → 추세장 유리, 횡보 불리.
- 이틀: 지수 +10%, −10% → 지수 −1.0% vs 3배 ETF 130→91(−9.0%).
- 비용 3겹: 운용보수 연 1% 안팎, 스왑·차입비용(2배분, 금리 5%면 연 10%), 리밸런싱 마찰. 일 하락: −5%→−15%, −10%→−30%, −15%→−45%, −20%→−60%; 지수 −33.4%면 이론상 0(서킷브레이커 −7/−13/−20%).
