- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 오해 1 지수 10%→30% (일간 3배) / 2 규칙대로면 잃지 않는다(분할도 손실 가능, 실탄 소진 시 종료) / 3 여윳돈 아니어도 된다 / 4 최신 버전이 무조건 좋다 / 5 SOXL 수익률이 높으니 SOXL로 시작(변동성·끌림 큼, 초심자는 TQQQ 단일).
- 자기 점검 3문항: 횡보 −20%여도 규칙 지킬 수 있나 / 몇 년 묶어도 되는 돈인가 / 이 버전이 왜 그렇게 사고파는지 설명 가능한가.
