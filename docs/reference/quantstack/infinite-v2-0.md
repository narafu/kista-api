## 규칙 (2021년 6월, 과거 버전)
- 핵심: 40분할, 매일 1회치 LOC 매수 시도. 전반전(1~19회차)은 LOC평단매수+LOC큰수매수, 후반전(20회차~)은 평단 아래 매수만. 40회 소진 시 쿼터손절.
- 원금/분할: 40분할로 1회 매수시도액 결정; 한 종목 1회 매수분으로 최소 2주 이상 살 수 있어야 함; 여러 종목 시 원금 독립.
- 매수 전반전(1~19회차): 1회분 절반 LOC평단매수(평단), 절반 LOC큰수매수(평단+5%, 최대 +5% 초과 금지).
- 매수 후반전(20회차 이상): 1회분 전체 평단 아래 LOC매수, 평단 위에서는 절대 매수 안 함.
- 공통: 매일 1회치만 시도(어제 0.5회 샀다고 오늘 1.5회 금지); 급등락 시 정액법 유지(개수 변동); 장중에 이미 평단 아래면 장중매수 가능.
- 매도 전반전: 전량 평단+10% 지정가(애프터지정가), 프리장 시작(저녁 5시)에 걸어 프리~본~애프터 유지. 후반전: 평단+5%와 +10%로 반반 분할매도; +5%만 매도되면 남은 물량을 진행률 기준으로 재개.
- 소진: 40회차 모두 소진 시 쿼터손절 모드(상세 규칙은 이 페이지에 없음; V2.2 참고).
- 5줄 요약: 첫 종목 진입 시 RSI 고려(되도록 60 이하) / 큰수매수 평단+5% 넘기지 말 것 / 20회 이상은 평단 아래 1회치만 / 20회 이상 5%·10% 절반씩 익절 / 소진 시 쿼터손절.
- 주의: 평단 +5%~+9.9% 구간은 매수도 매도도 없음. 목적은 40회 소진과 "영혼법" 상황 감소(수익률 극대화 아님).
## 해설 (quantstack)
- 예: 원금 $40,000, 1회 $1,000, 첫날 종가 $50에 20주 → 평단 $50. 둘째 날 주문 $500@50.00 LOC, $500@52.50 LOC, 전량 @55.00 지정가. 종가별 결과: $49 → 둘 다 체결(약 20주); $51 → 52.50만 체결(약 9주); $53 → 무체결; $56 → 전량 익절·사이클 종료.
- 데드존(+5%초과~+9.9%), 평단 위 매수 이유(추세 참여 장치), 미해결 문제: 19→20회차 불연속, 회차 정의 모호(절반 체결은 몇 회차인가 → V2.2에서 금액 기준 T).
## 불명확
- "회차"가 날짜 기반인지 체결 기반인지 이 버전에서 정의되지 않음. 쿼터손절 절차 본문 없음. 큰수매수의 "최대 +5% 초과 금지"와 "평단+5% 지점"의 관계(정확히 +5%인지 이하인지)는 문면상 모호.
