# 백테스트를 어디까지 믿어야 하나 (analysis/backtest-trap/)

- 원본 URL: https://quantstack.app/analysis/backtest-trap/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 5가지 한계: 구간 편향(TQQQ 2010 상장, 2011~2020 강세·제로금리; 닷컴 나스닥 −78%, 회복 약 15년), 조달비용(2배 차입, 금리 5%→연 10% 안팎, 보수 약 0.9%), 생존 편향(−33% 일 이론상 0, 블랙먼데이 −22%→3배 −60%), 과최적화(파라미터 조금 바꿔 급변하면 잡음), 규칙 100% 준수 가정.
- 믿을 것: 구조적 비교(G↑ 현금비중↑, 밴드폭 무관, 20분할은 모든 것이 2배 속도). 믿지 말 것: 절대 수치(몇 배, 연수익, MDD). 봐야 할 것: 가장 깊은 골짜기에서 규칙대로 주문 가능한가.
