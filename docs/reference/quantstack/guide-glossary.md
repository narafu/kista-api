# 레버리지 ETF·규칙매매 용어 사전 (guide/glossary/)

- 원본 URL: https://quantstack.app/guide/glossary/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 종목·상품: 레버리지 ETF(일간 수익률 배수 추종); TQQQ(나스닥100 3배); SOXL(미국 반도체 지수 3배, TQQQ보다 변동성 큼); 변동성 끌림.
- 주문: LOC; LOC평단/LOC큰수 매수(평단 기준과 그보다 높은 값 기준 LOC 매수); 프리마켓/주간장(한국 낮 시간대 정규장 중 매매로 정의, 비권장); MOC(무조건 종가, 리버스 첫날 매도 등); 지정가(별지점 매도 외 나머지 3/4); 애프터지정가(V2.0/V2.1 매도); 부분 체결(V4.0 T+0.5); 서머타임(3월 둘째 일요일~11월 첫째 일요일, 프리장 시작 17↔18시).
- 무한매수법: 회차 T(V2.2 매수누적액÷1회매수액, V4.0 단순화); 별지점/별%; 전·후반전; 쿼터손절/쿼터매도(V3.0부터 통일); 리버스모드; 1회 매수액(V2.2까지 원금÷분할수, V3.0 반복리, V4.0 잔금÷(분할수−T) 매일); 분할 수(20/30/40, 평단 무관·속도 결정); 데드존(V2.0 +5%초과~+9.9%); 반복리(V3.0, 수익의 절반을 40분할 반영·나머지 보관); 무한매도(V4.0 리버스, 20분할 1/10·40분할 1/20 매일); 잔금; 가상증액(V2.1, +20% 이상 비권장).
- VR: V; V 갱신 공식(대체로 다음 V = 현재 V + P/G); Pool; 적립/거치/인출식; G(/10≈현금 13%, /40≈32%); 밴드(±15%); 사이클(2주); Pool 사용 한도(75/50/25); 수익률 순서 위험.
- 일반: 평단; 조화평균(n/Σ(1/pᵢ)); MDD; 과최적화; 세금 드래그; 양도소득세(250만 공제 후 22%, 5월 신고); 통합증거금.
- 불명확: "회차 T" 항목의 "V2.2 기준 대략"은 설명이 축약. 별지점 "아래는 매수 영역, 위는 매도 영역"은 단순화(실제는 매수=별지점−0.01, 매도=별지점).
