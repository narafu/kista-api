# VR 5.0 핵심 용어 & 공식 (vr/overview/)

- 원본 URL: https://quantstack.app/vr/overview/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 공개 시점 2022년 4월(VR 5.0). 범위: V·Pool·G·밴드 정의와 V 갱신 공식.
- 핵심 개념: TQQQ(또는 레버리지 ETF) 평가금을 가상의 V 곡선에 맞춰 흐르게 하고 벗어나면 리밸런싱. 평균 현금 13~32%.
- 용어표/공식/예시(9350$)/G 값 가이드표/권장값(시작 /10 적립·거치, /20 인출, 1년 단위 /11→/12→/13, 금액 커질수록 /30 이상)/밴드폭(±15% 오피셜, ±10% 가능, ±5%·±20% 허용, 영향 미세)/Pool 한도(적립 75% 적립 후, 거치 50%, 인출 25% 인출 후; 이후 점차 낮추는 방향)/유형별 특징(시스템·공식·매수매도 완전 동일, 전환 자유) → 모두 value-rebalancing.md §A.
- G 표 callout: TQQQ 3배, QLD 2배 가정. /40 이어도 QLD(2배) 대비 위험 낮고 수익 높음.
- 해설: V는 매수 이력과 무관 → 물타기 없음, 평단보다 싸게 파는 것이 규칙(callout: 평단 기준으로 손해 보고는 못 판다고 생각하면 VR이 아님). 요약 문장 "P가 많을수록 V가 빨리 오르고(P/G), 평가금이 V에서 밴드만큼 벗어나면 다시 V로 되돌린다". Pool 한도 순서의 이유(다시 채워질 수 있는가: 적립 O 75 / 거치 매도만 50 / 인출 마이너스 25). 밴드 안 무거래는 정상.
