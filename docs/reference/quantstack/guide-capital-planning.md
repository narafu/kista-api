# 시작 전 자금 설계 (guide/capital-planning/)

- 원본 URL: https://quantstack.app/guide/capital-planning/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 1단계 기간: 최소 1년(가능하면 2년) 손 안 대도 되는 돈. 제외: 6개월 내 지출, 비상금(3~6개월), 대출금, 신용·미수. 40분할 소진 약 2개월, 리버스 포함 사이클 반년 이상 가능, VR 수년.
- 2단계 1회 매수액 하한(TQQQ $80, 환율 1,400 → 1주 ≈ 11.2만원): 500만원(40분할 12.5만 ≈1주 부적합) / 1000만(25만 ≈2주 빠듯) / 2000만(50만 ≈4주 가능) / 4000만(100만 ≈8주 여유). 선택지: 분할↓(두 배 빨라짐)/저가 종목/원금 모일 때까지 대기.
- 3단계 최악 역산: −50% 가정, 원금 = 감당 손실 L ÷ 0.5. 500만→1000만, 1000만→2000만, 2500만→5000만, 5000만→1억. 2·3단계 충돌 시 3단계 우선.
- 4단계 계좌 분리: 생활·비상(예금/CMA) / 방법론 원금(전용 증권계좌) / 대기자금(별도). 전용 계좌여야 평단 오염 없음.
- 5단계 병행 시 합산 위험(예 감당 손실 2000만이면 합산 원금 ≤4000만). "원금 독립"은 계산 분리 의미, 위험 독립 아님.
- 6단계 체크리스트 10항(1년 여윳돈, 대출 無, 비상금, 최소 몇 주, −50% 감당, 합산, 버전·분할 고정, LOC 지원·마감, 소진 국면 절차 읽음, 비용 반영).
