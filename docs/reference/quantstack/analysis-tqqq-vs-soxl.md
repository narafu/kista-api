# TQQQ vs SOXL (analysis/tqqq-vs-soxl/)

- 원본 URL: https://quantstack.app/analysis/tqqq-vs-soxl/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 파라미터 비교(V3.0/V4.0): 별% 시작값 TQQQ 15% / SOXL 20%; 40분할 15−0.75T / 20−T; 20분할 15−1.5T / 20−2T; 리버스 종료 −15% / −20%.
- 구조: TQQQ=나스닥100(100종목·다업종), SOXL=반도체 지수(30종목 안팎, 단일 업종, 경기순환). 끌림은 변동성 제곱 → 변동성 1.3배면 끌림 ≈1.7배.
- 해석: 시작값 큼=SOXL 반등폭이 커 초반 익절 방지, 기울기 큼=T=분할수/2에서 0을 지나도록, 종료 −20%=진동 걸러냄. 세 파라미터가 같은 원리("진폭이 크니 문턱도 넓게"). 표(40분할): T=1 +14.25/+19.0, T=10 +7.5/+10.0, T=20 0/0, T=30 −7.5/−10.0, T=40 −15/−20.
- TQQQ+SOXL 병행은 분산 아님(같은 방향, 동시 소진 전제 원금 설계). TQQQ 먼저 권장 근거: 규칙 훈련, VR은 TQQQ 기준 설계. SOXL 고려: 소진·리버스 경험, 손실 감당, 반도체 관점.
