## A. 규칙
### A1. 용어
| 용어 | 의미 |
|---|---|
| V (Value) | TQQQ 평가금의 기준선(목표 평가금). 2주마다 갱신 |
| P (Pool) | 보유 현금 |
| G (Gradient) | V 기울기 결정 분모. 클수록 V 성장↓ 안정적 |
| 밴드 | V×0.85 ~ V×1.15 (±15% 오피셜). 벗어나면 매수/매도로 밴드 내 복귀 |
| 상승률 | 다음 사이클 V에 더해지는 값(P/G) |
| 사이클 | 2주 1회. V, 매수표, 매도표 모두 갱신 |
### A2. V 갱신 공식
```
다음 V = 현재 V + P/G ± 적립금(또는 인출금)      // 적립식 +, 거치식 0, 인출식 −
통일식: 다음 V = V + P/G + C   (C>0 적립식, C=0 거치식, C<0 인출식)
```
예: 매 사이클 250$ 적립, V=9000, P=1000, G=10 → 9000 + 1000/10 + 250 = 9350$.
### A3. 밴드
상단 = V×1.15, 하단 = V×0.85 (±15% 오피셜). ±10% 가능(수익·위험 미세 증가, 거래 바쁨), ±5%·±20% 커스터마이징 허용. 밴드폭 영향 매우 미세, 핵심은 G. (백테스트의 비교 대상 "기존 +25%/−20% 비대칭" 밴드가 원래 방식이었다고 서술. 사이트에서 최소·최대 허용 밴드폭을 별도로 규정하는 문장은 없음 → 불명확 U3)
### A4. 판단
- 평가금 > 상단 → 매도: 평가금이 V로 돌아올 만큼 매도(목적지는 상단이 아니라 V). 받은 현금은 Pool.
- 평가금 < 하단 → 매수: 평가금이 V에 도달할 만큼 매수, 단 Pool 사용 한도 준수.
- 밴드 안 → 거래 없음. 매도·매수 모두 평단과 무관(평단보다 낮아도 V상 매도 신호면 매도).
### A5. Pool 사용 한도 (한 사이클 매수 시 사용 가능한 Pool 비율 상한)
| 유형 | 한도 | 자금 흐름 | 권장 G 시작 | 난이도 | 원 방법론 공개 운용 사례 |
|---|---|---|---|---|---|
| 적립식 | 적립 후 Pool의 75% | 매 사이클 +적립 | /10 | 쉬움 | VR 2~4기 |
| 거치식 | Pool의 50% | 없음 | /10 | 보통 | VR 0~1기 |
| 인출식 | 인출 후 Pool의 25% | 매 사이클 −인출 | /20 | 어려움 | VR 5기(2025-07~) |
이후 사용 제한은 점차 낮추는 방향(75→50→25 등)으로 운용 가능, 공격/방어 모두 선택 가능.
### A6. G값
| G | 수익률 레버리지 | 위험도 레버리지 | 평균 현금보유 | 평균 P/V |
|---|---|---|---|---|
| /10 | 2.98배 | 2.37배 | 13.2% | 0.152 |
| /20 | 2.74배 | 2.18배 | ~21% | ~0.27 |
| /30 | 2.53배 | 2.03배 | ~27% | ~0.38 |
| /40 | 2.38배 | 1.91배 | 31.84% | 0.4672 |
(TQQQ 3배, QLD 2배 가정, 2011~2020 거치식 백테스트.) 권장: 적립·거치 /10 시작, 인출 /20 시작(이상, 이후 /30). 1년 단위로 /11→/12→/13… 점진 안정화. 금액 커질수록 /30 이상 권장.
### A7. 사이클 절차 (2주 1회, 모든 유형 동일)
1. 새 V 계산(위 공식). 2. 밴드 재설정(이전 밴드 재사용 금지). 3. 평가금 vs 밴드 판단. 4. 매수라면 Pool 한도 적용. 5. 목적지=V. 6. 지정가 또는 LOC로 주문.
- **2주치 주문표 작성**: 매수·매도 모두 지정가 또는 LOC로 2주치 예약주문 가능. 사이클 첫날 매수표·매도표를 미리 만들어 두면 2주간 판단 불필요. 예약주문이 모델 포트폴리오 지정가보다 유리하게 체결되면 그대로 사용 가능. (표의 구체 가격 간격·수량 산식은 사이트에 없음 → U1)
- Pool 소진: 하락장에도 매수 불가(대기). 적립식은 다음 적립금으로 복구, 거치·인출식은 상승 후 매도로 Pool이 복구될 때까지 홀드.
- 매도가 덜 걸리거나 과매수 시 다음 사이클 V 갱신에서 자연 조정. 유형 전환은 수개월 단위 OK, 2주 단위 금지(미리 계획된 변경만).
- 사이클 날짜: (해설) 0일차 요일 기준 격주 같은 요일 고정.
### A8. 종목·공통 원칙
TQQQ(레버리지 ETF) 중심(VR은 TQQQ 기준 설계, 2배 등 다른 배수에도 적용 가능하다는 서술은 해설에 있음). 핵심은 매도. 길게 가려는 방법론, 무리하지 않는 페이스. 평균 현금 13~32% 보유하며 레버리지 수익 확보.
### A9. 유형별
- **적립식**: V에 +적립금. VR 2~4기, 소액 장기(월 10만원 수준 수십 년)도 같은 공식. 월급 인상 시 N배수. 거치식과 동시 진행 권장. 무리한 적립 금지. 최종 목표는 인출식.
- **거치식**: 적립·인출 0, 다음 V = V+P/G. VR 0·1기. 적립식에서 전환 시 TQQQ 개수를 거치식 모델 포트폴리오 개수에 맞추고 남는 TQQQ는 자유 처리(홀드/급전 시 매도).
- **인출식**: 다음 V = V+P/G−인출금. 최종 목표. 시작 G /20 이상→/30. 공개 사례: 블로그 196주차~252주차 개인 인출식(초기 월 600만원→점진 증액→현재 월 1500만원). VR 5기(2025-07~) 첫 공개 운용, 원금 2만$(N배수 가능), 팬딩에서만 중계(카페 외부). Pool 소진 시 인출 중단, 급락 시 일시 거치식 전환 가능. 운영 난이도 최상.
- **유형 전환**: 공식·사이클·매매 방식 동일, 차이는 자금 흐름뿐.
  - 적립→거치: 기존 TQQQ 개수를 거치식 모델 개수에 맞춤(이미 거치식 중이면 1배수 증가 방식 병합), 남는 TQQQ 자유 처리, 소액(월 10만원) 적립 병행 가능.
  - 거치→적립: 적립식 목표 N배수로 TQQQ 개수 조정(예: 적립식 모델 367개, 2배면 734개), 모자라면 거치식에서 가져오고 더 모자라면 추가 매수.
  - 거치↔인출(일시): 인출식 중 큰 하락장 시 하락장 동안 Pool 매수 소모 → 잠시 거치식 운영, Pool 복구 후 인출식 복귀(생활비 여유 있으면 인출 안 해도 됨).
  - 원칙: 수개월 단위 OK, 2주 단위 금지, 계획된 전환(새벽 갑자기 금지), 적립+거치 동시 진행이 비중 조절에 유리.
### A10. 백테스트 (2011~2020, 거치식 기준, 적립/인출도 유사)
- 밴드폭 비교(G /10 고정): 기존(+25%/−20%) 원래 방식 비대칭 / ±15% 오피셜 균형 / ±10% 거의 매 사이클 거래, 수익·위험 미세 증가 / ±5% 매우 빈번. P/V 흐름 큰 차이 없음.
- 적립식 예시: 5000$ 시작 + 매 사이클 250$ 추가, 10년 후 약 136만$(거치식 /10 기준과 비교).
- 결론: 주 조절 변수 G(/10 공격~/40 안정), 밴드폭은 부가. /10 시작→금액 커질수록 G↑, 인출식 /20 이상.

## B. 해설이 제시한 수치 (검증 벡터)
- 거치식 G=/10, ±15%, V=10000, P=1500, 평가금 10000:
  - 사이클1: V=10000+150=10150, 상단 11672.5, 하단 8627.5. 평가금 12000 → 매도 1850(=12000−10150). 종료: 평가금 10150, Pool 3350, P/V 0.330.
  - 사이클2: V=10150+335=10485, 상단 12057.75, 하단 8912.25. 평가금 8500 → 필요 1985(10485−8500); 거치 한도 3350×50%=1675 → 1675만 매수. 종료: 평가금 10175, Pool 1675, P/V 0.160.
  - 사이클3: V=10485+167.5=10652.5 (상승률 150→335→167.5).
- 적립식 V=10000, P=1500, G=10, 적립 250: V 10000→10400(+4.0%)→10800(+3.8%)→11200(+3.7%); 같은 조건 거치식은 사이클당 +1.5%.
- 0일차 세팅(해설, 원 방법론은 초기 분배 미명시): TQQQ 매수액 = 원금/(1+P/V), Pool = 원금−매수액. G=/10 → P/V≈0.15 → 원금/1.15 (5000→약 4350/650, 10000→8700/1300, 20000→17400/2600); G=/20 → 0.27 → /1.27. 정수 주 매수, 체결 후 실제 평가금=V₀, 남은 현금=P₀, 0일차엔 V 갱신·밴드 판정 안 함. V₁ = V₀+P₀/G (예 8700+130=8830, 상단 10154.5, 하단 7505.5). TQQQ 70%로 시작도 가능, 시작값은 중간에 고치지 않음.
- V 성장률 = (P/V)/G. 연환산(26사이클): /10 1.52%→+48%, /20 1.35%→+42%, /30 1.27%→+39%, /40 1.17%→+35%.
- 인출식 지속 조건: 인출금 ≤ P/G (예 V=200000, G=/20, P≈42000(21%) → 사이클당 2100, 연 26사이클 ≈54600, V의 ~27%).
- 밴드 ±10% vs ±15% 예: V=10000, 평가금 12000까지 상승 시 조정 후 평가금은 모두 V, Pool 증가 +1000 vs +1500.
- 해설 체크리스트(사이클마다): Pool 확인 / 새 V / 새 밴드 / 밴드 밖 여부 / Pool 한도 / 목적지 V / 지정가·LOC. 흔한 실수: 밴드 경계까지만 되돌림, 평단으로 검열, 사이클 앞당김·미룸.
- 인출식 시작 체크리스트: 계좌 밖 6개월 생활비, 인출금≤P/G, G≥/20, Pool 한도 25%, 하락장 인출 중단 기준, 적립/거치 1년 이상 경험, 양도세 반영.
- 전환 시 한도 변화: 적립→거치 75→50, 거치→인출 50→25, 인출→거치 25→50(공식은 바꾸고 한도를 안 바꾸는 실수 주의).

## C. 사이트 코드 구현 (포트폴리오, 로그인 전용 — 사이트의 해석)
- Pool 한도: vr_install 0.75, vr_withdraw 0.25, 그 외(거치) 0.5. G 기본: 인출식 20, 그 외 10. 밴드폭 기본 15%. 사이클 주기 상수 14일.
- 판정: 상단=round2(V×(1+밴드%/100)), 하단=round2(V×(1−밴드%/100)), 평가금=round2(보유×현재가). 평가금>상단 → 매도 수량 `floor((평가금−V)/현재가)`; 평가금<하단 → 매수액 `min(V−평가금, max(0,Pool)×한도)`, 수량 `floor(매수액/현재가)`.
- 다음 V = round2(V + (G>0 ? Pool/G : 0) + 흐름), 흐름 = 적립식 +|입력|, 인출식 −|입력|, 거치 0. 갱신 버튼은 입출금 거래를 자동 기록.
- Pool = 원금 + 입금 − 출금 − 매수액 + 매도액(거래 내역 누적).
- 0일차(보유 0): P/V 표 보간 (G=10→0.15, 20→0.27, 30→0.37, 40→0.47; 그 사이 선형, 10 미만은 0.15), TQQQ 금액=원금/(1+P/V), 수량 floor(금액/현재가); 0일차에는 Pool 한도 미적용.
- 전략 키: vr_install, vr_lump, vr_withdraw. 심볼 기본 TQQQ.

## D. 해설의 핵심 주장 (규칙 아님)
- 기준점이 평단이 아니라 V(이력 무관) → 물타기 개념 없음, 평단 아래 매도 정상. 무한매수법과 달리 사이클 끝 없음, 2주 판단.
- P/G 자동 안정화: 매도→P↑→V 가속, 매수→P↓→V 감속. Pool 한도는 그 시차를 메우는 2차 안전장치.
- G는 평균 현금 비중 손잡이(G×4 → 현금 2.4배, 수익 레버리지 −20%). 밴드폭은 목적지를 안 바꾸고 빈도만 바꿔 영향 작음(좁으면 비용↑).
- 한도 순서(75/50/25)는 "Pool이 다시 채워질 수 있는가"의 답.
- 백테스트 한계: 2011~2020 강세·저금리, 비용 반영 불명, 절대 수익·MDD 신뢰 금지, 구조적 비교(G↔현금비중, 밴드폭 무관, 수익레버리지>위험레버리지)만 신뢰.
- 인출식 위험: 수익률 순서 위험(−40%→+60% vs +60%→−40%), 대응=하락장 거치식 전환(계좌 밖 생활비 필요).
- 적립식 함정: 하락장 증액, 적립 건너뛰기, 무리한 적립. 거치식 주의: 거래 없는 기간 김, Pool 마르면 시간이 해결 안 함, 남는 TQQQ는 VR 평가금에서 제외.

## E. 불명확·누락
- U1: 2주치 주문표(지정가/LOC) 가격 간격·수량 배분 산식 없음. 사이트가 말하는 것은 "첫날 매수표·매도표를 미리 만든다"뿐.
- U2: V 갱신식의 P가 갱신 시점의 어떤 Pool인지(적립금 입금 전/후). 한도는 "적립 후 Pool", "인출 후 Pool"이라고만 서술. 코드는 거래 누적 Pool + 흐름을 V에 더함.
- U3: 밴드폭 허용 최소·최대 규정 없음(±5~±20% "허용"만 언급). 상·하단 비대칭(+25/−20)은 과거 방식 언급뿐.
- U4: "VR 5.0(2022-04)"과 "VR 5기(2025-07~)"의 '5'는 다른 의미(버전 vs 운용 기수). 개요 표의 "VR 0~1기/2~4기" 도 기수.
