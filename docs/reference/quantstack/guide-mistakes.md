# 초보가 흔히 하는 실수 (guide/mistakes/)

- 원본 URL: https://quantstack.app/guide/mistakes/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 1~10: 감당 못 할 원금 / 규칙 중간 변경 / 버전 갈아타기 / 비오피셜 종목 / LOC를 시장가처럼 / 주문 시간 놓침(프리장 시작 17/18시) / 평단·회차 손계산 / 하락장을 고장으로 착각 / 현금(잔금·Pool) 무시 / 남의 수익 인증에 흔들림.
- 11~16: 계좌 미분리(한 계좌=한 설정) / 미체결 몰아서 처리(오늘 몫만) / 하락장 원금 추가(원금 변경은 보유 0 시점에만; 리버스 중 외부 자금 금지) / 소진 국면 절차 미리 안 읽음 / 비용 미반영(사이클 손익분기 1% 안팎) / 규칙을 "조금만" 개선(예: 별지점보다 0.5% 낮게, 이번만 +8%에 매도).
- 국면 분류: 시작 전(1,3,4) / 평온(7,6,10) / 하락(2,8,9). 한 줄 체크리스트·확장 체크리스트(시작 전/매일/하락).
