# 환율과 원화 수익률 (basics/fx-effect/)

- 원본 URL: https://quantstack.app/basics/fx-effect/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- quantstack 자체 계산·해설(원 방법론 규칙 아님)

- 원화 수익률 = (1+달러수익률)(1+환율변동률)−1. 표: 주식 +10%: 환율 −10/−5/0/+5/+10% → −1.0/+4.5/+10.0/+15.5/+21.0; 주식 −10%: −19.0/−14.5/−10.0/−5.5/−1.0.
- 환율 개입 3시점(환전, 보유, 재환전). 기록 예: 1350원 → 1300원, $10,000 → $11,200(+12.0%) → 원화 +7.9%(−4.1%p). 세금은 매수·매도 시점 환율 환산(달러 −5%여도 원화 +8000원 과세 가능). 환헤지(H) 상품은 헤지비용·상품 부재로 대안 아님.
