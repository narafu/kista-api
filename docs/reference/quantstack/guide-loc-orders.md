# LOC·MOC 주문 완전 정리 (guide/loc-orders/)

- 원본 URL: https://quantstack.app/guide/loc-orders/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 주문 유형: 지정가(장중, 유리할 때만) / 시장가(즉시) / LOC(종가 결정 시점, 종가가 지정가보다 유리할 때만) / MOC(종가, 무조건) / LOO·MOO(시가).
- LOC 매수 $50: 종가 49.50 → 체결가 49.50(지정가 아닌 종가); 50.00 체결; 50.30 미체결(소멸). LOC 매도 $60: 종가 61.00 체결(61.00), 59.50 미체결. 장중 가격 무시(장중 45까지 빠져도 종가 52면 미체결).
- 왜 LOC: 하루 한 번 판단, 한국 생활리듬(프리장 시작 직후 주문 후 취침), 종가=합의가격, T가 하루 한 칸. MOC: 반드시 실행돼야 하는 거래(리버스 첫날), LOC: 조건부 거래.
- 실전: 증권사 LOC 지원/명칭(종가지정가·장마감지정가), MOC 미지원 증권사 있음; 접수 마감 장 마감 10~20분 전(타 페이지는 5~10분); 서머타임(3월 둘째 일요일~11월 첫째 일요일) 1시간 이동; 통합증거금·예수금 묶임; 부분 체결(1.5회분 금지); 미체결 자동 소멸(매일 새로); 소수점 매매는 LOC 미지원 가능→정수 주.
- Q&A: 매수·매도 동시 걸어도 됨(V4.0 −0.01 이유; 매도엔 보유수량, 매수엔 예수금 묶임); V2.0엔 장중 평단 아래 장중매수 예외; 종가=지정가면 LOC매수 체결(동시호가 물량 문제로 미체결 가능); 프리·애프터는 LOC 무관.
