## 규칙/사실
- 미국 3배 레버리지 ETF(TQQQ·SOXL)를 원금 분할, 매일 규칙으로 매매. 2021년 첫 정식 규칙(V2.0) 이후 다섯 차례 개정(V2.0, V2.1, V2.2, V3.0, V4.0 일반/리버스), 현재 V4.0(2026-03).
- 버전 히스토리: V2.0 2021-06(LOC평단/LOC큰수 매수, 전/후반전, 쿼터손절) / V2.1 2021-11(매도 LOC 추가, 전반 2단·후반 3단) / V2.2 2022-12~2023-05(회차 T·별% 공식, 전·후반 매도 통일; "2023 오피셜") / V3.0 2024-06(20분할, 수익 반복리, 쿼터손절→쿼터매도) / V4.0 일반 2026-03(T 단순화, 1회매수금=잔금/(분할수−T)) / V4.0 리버스 2026-03(소진 시 무한매도+쿼터매수).
- 공통 원칙(전 버전): 종목 TQQQ/SOXL 한정(타 종목 오피셜 아님); 모든 주문 LOC 기반, 프리장 시작 직후(서머 17시/비서머 18시) 주문; 주간장 금지; 여러 종목/분할 병행 시 원금 독립 설정.
- 용어: T(회차; V2.2부터 매수누적액/1회매수액, V4.0부터 가산식), 별지점/별%(평단 대비 매수·매도 기준), LOC, 쿼터매도(누적 수량 1/4; V3.0부터 쿼터손절→쿼터매도), 리버스모드(V4.0~).
- callout(주의): 버전 간 변경점 비교 자료, 규칙은 원저작자에 의해 개정될 수 있음.
