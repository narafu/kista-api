# 무한매수법은 왜 V2에서 V4까지 왔나 (analysis/version-evolution/)

- 원본 URL: https://quantstack.app/analysis/version-evolution/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 렌즈: 실탄 관리 / 기준 명확성 / 계산 부담. V2.x 기준 표준화, V3.0 후반전·소진 정비, V4.0 계산 단순화+리버스. 뼈대(분할매수로 평단 관리+기계적 익절) 불변, 최신이 항상 정답은 아님.
- 모순 표시: 본 글은 V2.0이 "회차(T)와 별지점"으로 규칙을 못 박았다고 하나 V2.0 페이지에는 T·별%가 없고 V2.2에서 도입. V3.0을 "별지점 공식을 전·후반으로 나눔"으로 서술하나 V3.0 페이지는 반복리·20분할이 핵심. 본 글은 해석 자료이므로 버전별 규칙은 각 버전 파일 기준.
