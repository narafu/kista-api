# VR의 G값과 밴드폭 (analysis/vr-parameters/)

- 원본 URL: https://quantstack.app/analysis/vr-parameters/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 사이클 성장률 = (P/V)/G. G표(26사이클/년): /10 P/V 0.152→1.52%→연 약 +48%; /20 ~0.27→1.35%→+42%; /30 ~0.38→1.27%→+39%; /40 0.4672→1.17%→+35%. 연환산은 평균 P/V 유지 가정.
- P/G 자동 안정화, Pool 한도는 시차 보완. 밴드폭은 목적지(V) 불변·빈도만 변경(±10%: 11,000 도달 시 +1000 / ±15%: 11,500 도달 시 +1500, 결과 평가금 동일 10,000). 실전: G는 신중(1년 단위 /10→/11), 밴드는 편하게, 하락장에서 G 낮추기 금지, 금액 커지면 G↑.
- 상세 수치는 value-rebalancing.md.
