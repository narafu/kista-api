# 분할매수의 수학 (analysis/split-buying-math/)

- 원본 URL: https://quantstack.app/analysis/split-buying-math/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- 전부 quantstack 자체 분석(원 방법론 규칙 아님)

- 평단 = 총 매수금액 ÷ 총 보유수량. 100→90→80→90 4일, 총 400$: 몰빵 4주 평단 100(−10%) vs 매일 100$ 분할 1.00+1.11+1.25+1.11=4.47주 평단 89.4(+0.6%).
- 물타기와 차이=규칙(금액·시점 고정). 분할 수 20/40(예 2만$: 1000$ vs 500$)는 평단 회복 속도↔버티는 기간. 100→90→80→70이면 평단 약 79.5이나 70은 여전히 손실.
