# 손실 회복의 비대칭 (basics/loss-recovery/)

- 원본 URL: https://quantstack.app/basics/loss-recovery/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)
- quantstack 자체 계산·해설(원 방법론 규칙 아님)

- 회복 필요 수익률 = L/(100−L): −5→+5.3, −10→+11.1, −20→+25.0, −30→+42.9, −40→+66.7, −50→+100, −60→+150, −70→+233.3, −80→+400, −90→+900.
- 3배: 지수 −10/−15/−20/−25% → ETF −30/−45/−60/−75% → 회복 필요 +43/+82/+150/+300% → 필요 지수 상승(단순) 약 +14/+27/+50/+100%.
- 물타기(100에 100주, 50이 됨): 무행동 평단 100 회복 +100%; 50에 100주 추가 평단 75 → +50%; 300주 추가 평단 62.5 → +25% (손실 규모는 커짐). 행동: −40% 아래 방치 금지, 회복≠지수 회복(새 사이클), 손실 금액을 볼 것.
