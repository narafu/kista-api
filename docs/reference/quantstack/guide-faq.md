# 자주 묻는 질문 (guide/faq/)

- 원본 URL: https://quantstack.app/guide/faq/
- 수집일: 2026-11-11 (사이트 표기 마지막 업데이트: 2026-09-14)

- 시작 전: 금액 기준=감당 가능성(1년 묶여 반토막이어도 무방); 무한 vs VR=성향; 종목=TQQQ·SOXL 같은 3배 ETF.
- 주문·운용: LOC=종가 기준 지정가; 주문은 프리마켓 직후(서머 17시/비서머 18시); "주간장(정규장 중)" 임의 매매는 규칙 일관성 훼손(※ 용어집은 주간장=한국 낮 시간대 매매라 정의 → 설명 불일치); T=회차, 별%=평단 대비 기준 퍼센트(V2.2~).
- 리스크: 계속 마이너스는 설계대로일 수 있으나 회복 보장 없음; 레버리지 장기 보유 문제(끌림); 손절은 고른 버전 문서 규칙(쿼터손절·쿼터매도 등).
- 사이트: 무료; 공식 방법론 아님(해석 권한은 고안자); 오류는 피드백 폼.
- 자금·비용: 원금 = 감당 손실의 2배 상한; 40분할 1회매수액<1주면 분할↓/저가 종목/대기; 20 vs 40분할은 평단 동일·노출/소진시간/별% 기울기가 다름; 비용 수치 수수료 0.07~0.25%, 환전 왕복 0.4~1%, 보수 연 0.9%, 양도세 250만 공제 후 22%, 사이클 손익분기 1% 안팎; TQQQ+SOXL은 분산 아님.
- 주문 실무: LOC $50에 걸고 종가 $47 → $47 체결(V4.0 첫 매수 10~15% 위 규칙의 근거); 장중 싸도 종가 기준; 미체결 소멸; 증권사 LOC 지원 확인; 매수·매도 동시는 보통 하나만 체결(−0.01).
- VR: 평단보다 낮은 가격 매도 신호 맞음; 목적지는 V; G 시작 적립·거치 /10, 인출 /20, G≈평균 현금(/10 13%, /40 32%); 밴드 좁혀도 수익 안 늚; 무거래 정상.
- 백테스트·기대수익: 10년 몇 배 믿지 말 것, 기대수익률 제시 안 함, 최악 골짜기에서 주문 가능한지 기준.
